AI Looki Guard
분석 메인 탐지 방식 제안 개요 구현 계획

Proposal Overview

중고거래 이미지 사기를 거래 전에 경고하는 보조 도구를 제안합니다.

AI Looki Guard는 중고거래 상품 사진이 AI로 생성됐거나 부분 조작됐을 가능성을 빠르게 보여주고, 사용자가 판매글 설명과 이미지 상태를 함께 확인할 수 있도록 돕는 분석 보조 서비스다.

분석 메인으로 이동 탐지 방식 보기
프로젝트 목표 사기 판별 전 단계의 위험 경고
MVP
  • 생성형 AI 이미지와 부분 보정 이미지를 빠르게 걸러낸다
  • 판매 설명과 실제 사진 상태가 맞는지도 함께 본다
  • 사용자가 추가 확인 행동을 하도록 근거를 설명한다

Why This Matters

제안 배경은 단순합니다. 사진은 믿기 쉽고, 검증은 어렵습니다.

01

생성형 AI 이미지

실제로 존재하지 않는 상품 이미지를 만들어 구매자를 속이는 사례가 늘고 있다.

02

부분 조작과 보정

흠집, 찍힘, 사용 흔적을 지우거나 흐리게 해 실제 상태보다 좋아 보이게 만들 수 있다.

03

일반 사용자 한계

구매자는 패턴, 노이즈, 메타데이터, 경계 흔적을 직접 확인하기 어렵다.

Core Idea

핵심은 “사기 단정”이 아니라 “위험 신호를 먼저 보여주는 것”입니다.

A

이미지 자체 분석

메타데이터, 압축 경계, 질감, 반복 패턴으로 생성·조작 가능성을 먼저 계산한다.

B

설명과의 교차 검증

판매 설명과 이미지 상태가 서로 맞는지 확인해 단순 사진 분석 이상의 근거를 제공한다.

C

위험도와 이유를 같이 표시

점수만 주는 것이 아니라 어떤 신호 때문에 의심했는지 문장으로 정리해 사용자 판단을 돕는다.

D

플랫폼 확장 가능성

향후에는 중고거래 플랫폼 업로드 단계에서 자동으로 경고를 띄우는 구조까지 연결할 수 있다.

Implementation Plan

구현 계획은 분석 정확도와 설명 가능성을 함께 높이는 방향입니다.

AI 모델

TensorFlow 또는 PyTorch 기반 CNN 모델로 실제 조작 이미지 데이터셋을 학습한다.

전처리

OpenCV로 노이즈, 경계, 압축 흔적, 패턴 특징을 전처리해 입력 품질을 높인다.

웹 UI

사용자가 사진을 올리고 결과를 이해하기 쉽게 볼 수 있는 웹 기반 분석 화면을 제공한다.

설명 레이어

분석 결과를 자연어로 다시 풀어 사용자가 추가 확인 행동을 결정하기 쉽게 만든다.

Roadmap

개발 흐름은 조사, 구현, 설명 강화 순서로 가져갑니다.

  1. 1

    자료 조사

    중고거래 사기 사례와 AI 생성 이미지 데이터셋을 수집하고 분석 지표를 정리한다.

  2. 2

    분석 MVP 구현

    업로드, 분석, 결과 표시가 되는 브라우저 기반 프로토타입을 만든다.

  3. 3

    모델 고도화

    CNN 기반 판별기와 실제 데이터셋을 붙여 단순 신호 기반 분석보다 정밀도를 높인다.

  4. 4

    설명과 연동 강화

    분석 결과 설명과 플랫폼 업로드 단계 자동 경고 흐름까지 확장한다.
