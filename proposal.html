Challenge Background

도전 배경과 목적

중고거래 플랫폼 이용이 늘면서 거래 사기 피해도 함께 증가하고 있다. 특히 생성형 AI 발전으로 실제 존재하지 않는 상품 이미지를 만들거나, 기존 이미지를 조작해 상태를 더 좋게 보이게 하는 사례가 생겼다. 이런 이미지는 일반 사용자가 육안만으로 판별하기 어렵기 때문에 거래 전에 위험 신호를 자동으로 보여주는 보조 시스템이 필요하다.

Core Idea

제안서 핵심 아이디어

사용자가 판매글 이미지를 올리면 시스템이 패턴, 노이즈, 메타데이터, 설명-사진 일치도를 분석해 조작 가능성을 점수와 근거로 보여준다. 핵심은 사기 여부를 단정하는 것이 아니라, 구매자가 위험도를 빨리 인지하고 추가 확인 행동을 하도록 돕는 것이다.

Implementation Plan

구현 기술은 제안서 방향에 맞춘다

  • TensorFlow 또는 PyTorch 기반 CNN 모델로 이미지 조작 분류 고도화
  • OpenCV 기반 전처리와 특징 추출로 데이터 품질 보강
  • Flask 또는 Streamlit 형태의 웹 인터페이스로 빠르게 검증

Expansion Path

이후에는 이렇게 확장한다

  • ChatGPT API로 분석 결과를 사용자 친화적인 문장으로 설명
  • 중고거래 플랫폼 업로드 단계의 자동 검수 기능으로 연동
  • SNS, 쇼핑몰 등 다른 이미지 검증 영역까지 확장 가능

Project Direction

“이미지가 진짜인지 단정하는 AI”가 아니라, 거래 전에 위험 신호를 먼저 보여주는 AI를 만든다.

이 화면은 제안서 설명용이다. 실제 시연은 메인 분석 페이지에서 하고, 탐지 방식 설명은 별도 로직 페이지에서 이어서 보여주면 발표 흐름이 더 깔끔해진다.
