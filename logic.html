Detection Logic

어떤 방식으로 조작 이미지를 의심하는지 설명합니다.

이 페이지는 AI Looki Guard가 단순히 “의심”만 표시하는 것이 아니라, 어떤 이미지 신호를 보고 위험도를 올렸는지 이해할 수 있도록 정리한 설명 화면이다. 현재 브라우저 분석 버전은 메타데이터, 압축 경계, 노이즈 분포, 경계선 자연도, 반복 패턴, 설명 불일치를 함께 본다.

  • 판매 설명과 사진 특징이 맞지 않으면 위험도를 추가로 올린다

Signal Breakdown

이 여섯 가지 신호를 합쳐 조작 가능성을 계산합니다.

메타데이터

JPEG 사진에 EXIF가 없거나 원본 정보가 부족하면 원본 촬영 파일인지 확인하기 어렵다고 보고 점수를 올린다.

압축 흔적

8픽셀 경계선이 내부보다 강하면 부분 편집 후 재저장됐을 가능성을 보고 압축 경계 점수를 준다.

노이즈 균일도

너무 매끈한 큰 영역이나 영역별 노이즈 편차가 크면 생성형 이미지 또는 국소 보정 흔적으로 본다.

경계선 자연도

강한 윤곽선과 채도 변화가 많으면 상품 외곽이나 흠집 주변을 편집했을 가능성을 추가로 반영한다.

패턴 반복

서로 먼 위치의 작은 타일이 지나치게 비슷하면 배경 복제, 인페인팅, 자동 채우기 흔적으로 의심한다.

설명 불일치

“A급”, “새상품” 같은 설명인데 편집 신호가 강하거나, 흠집 설명과 사진 상태가 어긋나면 점수를 더한다.

How It Works

실제 판정 흐름은 이렇게 움직입니다.

1

이미지 축소 샘플 생성

업로드한 사진을 브라우저 안에서 작은 분석용 샘플로 바꿔 밝기, 채도, 경계 계산을 시작한다.

2

픽셀 기반 신호 계산

그레이스케일, 그래디언트, 라플라시안, 타일별 분산을 계산해 압축 경계와 질감 이상을 찾는다.

3

설명 문구와 비교

판매 설명에 있는 흠집, 사용감, 새상품 같은 표현이 현재 이미지 신호와 맞는지 추가로 비교한다.

4

결과 단계화

합산된 점수를 기준으로 정상 가능성 높음, 의심 이미지, 조작 가능성 높음 단계로 나눠 보여준다.

Score Logic

점수는 이렇게 합산됩니다.

  1. 1

    신호별 점수 계산

    메타데이터, 압축 흔적, 노이즈, 경계선, 반복 패턴, 설명 불일치에 각각 부분 점수를 부여한다.

  2. 2

    0~100 범위로 제한

    부분 점수를 합친 뒤 0에서 100 사이로 잘라서 최종 위험도로 사용한다.

  3. 3

    35점 이상이면 의심

    35점 이상이면 “의심 이미지”, 65점 이상이면 “조작 가능성 높음”으로 단계가 올라간다.

  4. 4

    근거 문장 출력

    점수를 올린 신호만 골라 사용자에게 왜 의심했는지 자연어 근거로 정리해 보여준다.

Limits

이 도구가 바로 하지 않는 것

01

원본 확정 판정

이 결과만으로 원본 사진이라고 확정하거나 법적 증거로 쓰도록 설계된 도구는 아니다.

02

모든 편집 탐지

아주 정교한 리터치나 단순 색보정은 신호가 약하면 낮게 나올 수 있다.

03

사기 단정

최종 목적은 사기 확정이 아니라, 거래 전에 추가 확인이 필요한 게시글을 먼저 걸러내는 것이다.
