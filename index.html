Problem

중고거래 사진은 믿기 쉬운데, 검증하기는 어렵습니다.

01

생성형 AI 이미지

실제로 존재하지 않는 상품 이미지를 만들어 구매자를 속이는 사례가 늘고 있습니다.

02

상품 상태 조작

흠집, 파손, 사용 흔적을 보정하거나 지워 실제 상태보다 좋아 보이게 만들 수 있습니다.

03

검증 장치 부족

일반 사용자는 이미지의 패턴, 노이즈, 메타데이터를 직접 확인하기 어렵습니다.

Core Features

판별보다 중요한 것은 거래 판단에 바로 쓰이는 설명입니다.

A

이미지 생성·조작 가능성 분석

CNN 기반 모델로 이미지 패턴, 노이즈, 생성 흔적, 경계선 이상 여부를 분석합니다.

B

단계별 위험 결과

정상 이미지, 의심 이미지, 조작 가능성 높음처럼 사용자가 즉시 이해할 수 있는 단계로 표시합니다.

C

자연어 근거 설명

ChatGPT API를 활용해 “왜 위험한지”를 쉬운 문장으로 요약해 사용자 신뢰도를 높입니다.

D

플랫폼 연동 확장

향후 게시글 등록 단계에서 자동 이미지 검증이 이루어지도록 중고거래 플랫폼과 연동할 수 있습니다.

Demo Flow

사용자가 거래 전에 확인하는 흐름

  1. 1

    이미지 업로드

    중고거래 게시글의 상품 사진과 판매 설명을 입력합니다.

  2. 2

    AI 분석 실행

    이미지 패턴, 노이즈, 생성 흔적, 메타데이터를 함께 확인합니다.

  3. 3

    위험 등급 산출

    정상, 의심, 위험 단계로 결과를 정리해 바로 보여줍니다.

  4. 4

    근거 설명 제공

    사용자가 거래를 계속할지 판단할 수 있도록 핵심 이유를 설명합니다.

Build Plan

제안서 기준 구현 계획

AI 모델

TensorFlow 또는 PyTorch 기반 CNN 분류 모델을 구현하고, AI 생성 이미지 데이터셋으로 학습합니다.

이미지 처리

OpenCV로 노이즈, 경계선, 패턴, 보정 흔적을 전처리하고 모델 입력 품질을 높입니다.

웹 프로토타입

Flask 또는 Streamlit으로 이미지 업로드와 분석 결과 확인이 가능한 MVP를 구성합니다.

설명 생성

ChatGPT API로 판별 결과와 위험 근거를 자연어로 요약해 사용자에게 전달합니다.

Roadmap

1인 개발에 맞춘 단계별 추진 일정

초기

자료 조사와 데이터 확보

중고거래 이미지 사기 사례, AI 생성 이미지 데이터셋, 조작 탐지 기술을 조사합니다.

중간

모델 구현과 프로토타입

CNN 판별 모델을 만들고, 업로드와 결과 확인이 가능한 웹 화면을 연결합니다.

후반

설명 기능과 통합 테스트

ChatGPT API 설명 기능을 붙이고 전체 시스템을 테스트해 완성도를 높입니다.

Expected Impact

거래 전 이미지 신뢰도를 확인하는 작은 절차가 사기 피해를 줄입니다.

AI Looki Guard는 구매자가 육안으로 확인하기 어려운 위험 요소를 자동으로 발견하고, 플랫폼에는 사전 검증 절차를 추가할 수 있는 기반을 제공합니다. 향후 SNS, 온라인 쇼핑몰, 커뮤니티 마켓 등 이미지 신뢰성이 중요한 서비스로 확장할 수 있습니다.
